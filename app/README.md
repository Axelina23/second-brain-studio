# Second Brain Studio: app desktop
App Windows (poi Mac) per il second brain: parte grafica (Oggi, Chat, Appunti, Mappa, Inbox) e, a destra, terminali con il vero Claude Code (abbonamento, mod, hook) in linguette. Chiudendo la finestra resta nell'area di notifica, con notifiche di Windows.

- **Installare o aggiornare** (su ogni PC, dopo la sincronizzazione): `powershell -ExecutionPolicy Bypass -File Sistema\app\build.ps1`. Crea l'eseguibile e l'installer classico di Windows (Inno Setup, `winget install JRSoftware.InnoSetup`) in `Sistema\app\dist\Second Brain Setup <versione>.exe`, da condividere. Se l'app è chiusa lo lancia subito (barra di avanzamento, app riaperta); se è aperta compare "Aggiornamento pronto" nella barra di stato. `-SoloInstaller` crea solo l'installer.
- **Avvio da sorgente:** `python Sistema\app\main.py [--nascosta] [--nuova-chat] [--debug]`. Una seconda apertura mostra quella già aperta (`--nuova-chat` le fa aprire una chat).
- **Test:** `python -m pytest Sistema\app\tests -q`. Interfaccia senza Python: servi `web/` in http e apri `prova.html` (ponte finto con dati di esempio).
- **File:** `main.py` (finestra, area di notifica, istanza unica, notifiche), `ponte.py` (dati e azioni per l'interfaccia; riusa `../motore/`), `terminale.py` (pseudo-console + websocket locale), `icona.py` (icona), `web/` (Preact+htm senza build, xterm.js, marked, DOMPurify, font Figtree in `web/vendor/`).
- **Scorciatoie:** Ctrl+1…5 sezioni, Ctrl+Shift+T nuova chat, Ctrl+Shift+W chiudi linguetta, Ctrl+Tab cambia linguetta, Ctrl+S salva l'appunto in modifica; nel terminale Shift+Invio va a capo, Ctrl+C copia se c'è una selezione, Ctrl+V / tasto destro incolla.
- **Uso del piano** (barra di stato in basso, 5 ore e settimana): lo scrive `~/.claude/statusline.ps1` in `~/.claude/second-brain/uso.json` ogni volta che una chat di Claude aggiorna la riga di stato; senza chat aperte l'app mostra l'ultimo dato, attenuato, con l'ora nel suggerimento.
- **Cache e log:** `~/.claude/second-brain/` (`app-errori.log`, `notifiche.json`, `webview/`).
- **Design:** `PRODUCT.md`, contratto in `.impeccable/surfaces/`, stile "Chiostro di Santa Chiara" (maiolica: fondo blu notte, cobalto, limone per l'azione principale, verderame salvato, terracotta non salvato; le piastrelle dei progetti sbiadiscono con l'età degli appunti).
- **Progetti nuovi:** "+ Nuovo" nella sezione Progetti crea `Progetti/<Nome>/CLAUDE.md` + `Output/`, la voce in INDICE e l'aspetto della piastrella (`.piastrella.json`: fondo ed emblema); tasto destro su una piastrella per cambiarne l'aspetto.
- **GitHub:** riquadro in fondo alla barra laterale (`github.py`): accesso con codice (OAuth App "Second Brain Desktop", chiave nel Gestione credenziali), crea repository privato, Sincronizza (pull --rebase, commit, push), conflitti affidati a Claude. File trascinati nella pagina Inbox: copiati in `Inbox/` con la data davanti.
