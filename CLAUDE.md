# Second Brain Studio
App desktop per un second brain di file Markdown con Claude Code (`app/` interfaccia e processo, `motore/` moduli condivisi, `docs/`).

- **Prima di modificare aggiornamenti, GitHub o comandi esterni, e prima di ogni `build.ps1 -Pubblica` o `-Stabile`**: leggi e segui `docs/AGGIORNAMENTI.md`.
- Test: `python -m pytest -q` dalla radice. Errori dell'app: `~/.claude/second-brain/app-errori.log`.
- Mai dati personali veri in test, screenshot o `app/web/prova.html`: persone e progetti inventati.
