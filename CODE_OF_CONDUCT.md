# Code of conduct

Second Brain Studio is a small spare-time project. The rules are short:

- Be kind and patient. People here have different languages, experience and free time.
- Stay on topic and assume good faith. Disagree with the idea, not the person.
- No harassment, insults, discrimination or spam, in issues, pull requests or Discussions.
- Never post other people's personal data. Check logs and screenshots before attaching them.

Comments or issues that break these rules can be edited, hidden or closed, and repeat offenders blocked.
To report a problem, use the "Report content" option on the comment or open a
[private security advisory](../../security/advisories/new) and mention it there.
